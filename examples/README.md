# 商品封面上传示例

本目录的 [product-cover-sample.png](product-cover-sample.png) 是项目已有的 AI 生成苔藓生态瓶展示图的副本，不含个人信息。图片为 1448 × 1086 像素、约 2.28 MiB，可直接用于管理端手工上传。

1. 启动两个工程，登录 [管理端](http://localhost:8081/)，打开「商品管理 → 新增商品」。
2. 在「商品封面」中选择本目录的 PNG。等待「封面上传成功」，确认右侧预览及封面路径自动更新。
3. 可以手动填写下列示例资料，然后点击「保存商品资料」；保存后点击「上架商品」。

| 字段 | 示例 |
| --- | --- |
| SKU | `FC-DEMO-001`（须未被使用） |
| 二级分类 | 森林生态瓶 |
| 商品名称 | 林间一隅 · 桌面苔藓瓶 |
| 销售单价 | 99.00 |
| 显示排序 | 10 |
| 初始库存 | 20 |
| 商品简介 | 一瓶苔藓与绿植，为桌面添一份自然绿意。 |
| 商品详情 | 玻璃生态瓶搭配苔藓、蕨类与造景石。摆放于散射光处，按植物实际状态少量补水。 |

上传仅保存图片，点击「保存商品资料」后才与商品关联；未上架的商品不会出现在商城。以上为手工演示资料，不会自动写入数据库。
