# 方寸森林登录页

欢迎页沿用参考图的左右分栏布局：左侧森林视觉与故事切换，右侧品牌、账号入口和游客入口。账号页使用同一布局，提供用户名、密码、显示密码按钮和登录状态提示。按钮为柔和圆角矩形，桌面与窄屏均有布局规则。

## 访问与账号

| 地址 | 用途 |
| --- | --- |
| `http://localhost:8080/` 或 `/index` | 新欢迎入口 |
| `http://localhost:8080/login` | 商城账号表单 |
| `http://localhost:8080/register` | 创建商城账号 |
| `http://localhost:8080/main` | 商城首页，游客可直接访问 |
| `POST /login` | Spring Security 验证数据库账号 |
| `POST /logout` | 带 CSRF 的退出登录 |

教学商城账号为 `forest`，密码为 `Forest2026!`。这是本项目的 CUSTOMER 账号，和 MySQL 的 root 账号、邮箱账号无关。教学密码不是数据库密码。

新增账号脚本为 `database/03-demo-account.sql`。新环境按 01、02、03 顺序初始化；已有完整数据库只需执行 03，不重跑前两份。03 仅在用户名不存在时添加账号，不改写已有密码、角色或启停状态。初始化 PowerShell 脚本也会执行这一步。

## 登录行为

- 用户名从 store_user 查询，密码使用 BCrypt 校验，不在 Session 中保存原始密码。
- 仅 CUSTOMER 可从用户端登录；禁用账号与错误账号使用统一错误提示。
- 成功后进入 /main，导航显示安全的显示名与退出按钮。
- 登录失败不回显密码；数据库故障使用“暂时无法登录”提示。
- 登录、退出均保留 Spring Security 默认 CSRF 防护，登录后更新 Session ID。
- 登录后的动态请求会重新检查数据库账号状态和密码指纹，禁用、删除或重置密码后旧 Session 失效。
- 游客可浏览首页、分类与商品详情；购物车、订单与结算要求登录，具体流程见 [用户端功能说明](storefront.md)。
- 已提供注册和图片验证码；不接入微信、找回密码、记住登录或管理员登录。

## 验证

遵循用户要求，本次不执行 Maven 构建、测试或应用启动。新增的 AuthFlowTests 与 CustomerAccountServiceTests 供用户运行，覆盖成功登录、错误密码、禁用账号、管理员角色拒绝、CSRF、退出、会话禁用和数据库故障处理。MockMvc 与模拟 Mapper 不作为真实数据库事务或并发证据。

重启用户端后按以下顺序检查：

1. 根路径显示新欢迎页，故事箭头与进度条的三个位置可切换背景和文案；“先逛逛”进入商城。
2. “商城账号登录”在原页面右侧打开表单，左侧背景与文字不重播；密码默认隐藏，显示开关支持键盘操作。
3. 输入当前图片验证码与教学账号后进入商城，导航显示“森林旅人”。

5. 错误密码不会进入商城，密码不会回填。
6. 核对桌面 1366×768、1920×1080 和窄屏的可读性。

视觉素材与最终生成提示词见 [素材说明](assets.md)。

## 左侧水墨逐字显现

`static/js/ink-reveal.js` 从浏览器实际字体生成透明字形图集。通过 Range 测量原始文本中的每个字形，不把原文拆成单字 DOM 节点，保留原生字距、排版和语义。Canvas 通过 TextMetrics 的字形边界以及临时基线探针定位，不对文字做位移、缩放或抖动。

- 每个字形的阶段为 0.24 秒，相邻可见字形固定错开 0.045 秒；空格与换行保留但不消耗字形阶段。
- 标题与说明属于同一条连续时间线。品牌、英文引言与各组辅助文案分别从各自首字启动，块内保持相同的固定错开间隔。
- 图集 alpha 保存实际字形的抗锯齿覆盖率，使用 sigma=1 的归一化 5×5 高斯核；25 个采样点的偏移上限为约 5 个图集像素。
- 阶段进度 p 下，采样半径为 `5 × (1 − clamp(p / 0.7))³`。在前 70%（0.168 秒内）完成对焦；透明度同时按平滑曲线在完整 0.24 秒内从零升到原文字透明度。
- 原生 Canvas 加法合成 25 份带权覆盖率，再以 source-in 着色。采样偏移只用于卷积核，不改变字形最终屏幕坐标。背景图片、右侧纸色与 DOM 容器均不参与模糊。
- 字形四周预留 8 个图集像素，避免初始模糊被裁切；图集按设备像素比生成，倍率最多 2，不把 5 个图集像素误算为 5 个 CSS 像素。
- 显现结束后恢复原生 DOM 文字，清空透明画布；故事切换重新显现新标题与说明，窗口变化重新定位但不重置已有时间线。

背景图继续使用原有位置、尺寸及 object-fit。右缘另有一层与右侧面板同色的窄条遮罩，左边缘通过渐变羽化，在 1.1 秒内向右退出；移动的是遮罩，图片本身不移动或缩放。最终交界处还保留一层渐变羽化，在窄屏上下布局中改为底缘渐变。

系统启用“减少动态效果”时直接展示原生文字和完整背景。初始化失败时也保留原文，不让内容持续不可见。

已使用隔离的离线浏览器验证 25 点采样、权重归一化、实际字形 alpha、时间参数、透明画布边缘、图片与标题几何不变、故事重播、390px 窄屏和设备像素比 2。未执行 Maven 构建或启动 Spring Boot。

## 背景切换与页数指示

三页依次为自然摄影、水彩微森林、立体生态景观。后两张为从零生成的不同画风，三张实际尺寸一致。切换使用两个固定位置的图片层，新图的透明度遮罩在 1.1 秒内向右展开并保留羽化边缘，最后交界处仍然柔和；连续点击会切到最新请求的页面。

进度条为两个等长区间：第一页圆点位于左端（0%），第二页位于中点（50%），第三页位于右端（100%）。圆点左侧为 3px 白线，剩余部分为 1px 半透明线。点击三个位置、使用前后箭头或在进度条内按键盘左右键，均同步更新背景、文案和圆点。

## 右侧切换与商城入场

欢迎入口与账号表单之间仅替换右侧的 `data-auth-view`：旧内容用 170ms 渐隐，新内容用 380ms 从下方轻弹进入。左侧节点、图片位置和水墨时间线保持原状。地址栏、浏览器前进后退、密码显示开关和表单内的 CSRF 字段同步保留。表单仍向 Spring Security 的真实 `POST /login` 提交，失败只回填用户名，不回填密码。

注册页 `/register` 复用同一右侧过渡，支持账号、昵称、可选邮箱、密码确认和图片验证码。注册成功转到登录表单，不自动登录。登录与注册分别使用独立的 Session 验证码，2 分钟有效，每次提交验证后立即作废；点击图片刷新。验证码端点返回 PNG 和禁止缓存响应，不返回答案。Spring Security 在密码验证前检查登录验证码，CSRF 仍保持启用。

点击“先逛逛”时，先保持当前画面等待商城响应；原生页面快照再让左侧向左、右侧向右，在 520ms 内渐隐，结束同刻开始商城的 360ms 渐显。商城首屏参与整页渐显，屏幕下方的分类和商品通过 IntersectionObserver 在进入视口时依次浮现，每块只播放一次。启用减少动态效果时直接显示内容。

## 商品页退出与登录返回

导航退出按钮使用附近的 Popconfirm 气泡，可取消、按 Esc 或点击外部关闭。确认后带 CSRF 向真实 `/logout` 提交，异步响应为 204；随后读取服务器的游客页面，仅替换导航和购买控件，保留商品、主图、当前滚动位置和数量。若退出已成功但局部更新失败，则重新打开当前公开商品页；个人购物车/订单等受保护页面退出后返回商城首页。

游客的“加入购物车”先保留商品编号、数量与滚动位置，保持商品页可见，等待登录页准备好后再用 280ms 渐隐，结束同刻开始 360ms 渐显。购物车、订单和个人账号等游客入口复用相同的过渡与登录流程。登录成功后返回对应页面；商品页恢复数量，不自动执行加购。系统开启减少动态效果时直接切换。

登录、注册切换和验证码/密码失败均保留 `returnTo`。服务器只接受规范的 `/product?id=正整数`、`/cart`、`/orders` 和 `/account`，拒绝外部网址、协议相对地址、额外参数或溢出编号，防止任意跳转。退出登录的返回地址仍只允许公开商品页或商城首页。原有从欢迎页进入商城的左右退场保持不变。

新增返回地址、异步退出与 CSRF 等 MockMvc/规则用例，未执行。静态页面检查不代替真实身份、数据库与事务验收。

## 商城页面过渡

首页的“探索生态补给”、微景观等分类入口、商品卡片、面包屑、分页、GET 搜索筛选和商城导航，统一使用 280ms 渐隐、360ms 渐显。商城和认证页面同时启用跨文档 View Transitions。先保持原页面等待响应，再启动同一条页面快照时间线：新页渐显的延迟等于旧页渐隐时长，没有额外空白期。浏览器前进/后退保持相同效果，并保留原生地址、历史与滚动恢复。不支持原生快照的浏览器保持原页可见至交接，再渐显新页，不在网络加载前手动隐去原页，不插入额外历史记录。从欢迎页“先逛逛”进入商城仍使用左右各自退场，520ms 渐隐结束立即开始 360ms 商城渐显。

整页过渡时首屏直接参与页面渐显，避免同时触发一轮内容浮动；屏幕下方仍保留滚动进入时浮现。减少动态效果时关闭页面动画。新窗口、下载、站外链接和同页锚点保持原生行为，写操作表单不由页面导航脚本代为提交。
